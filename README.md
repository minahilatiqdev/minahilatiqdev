## Selected Work

<td width="100%">

**PAAI — Personal AI Coding Assistant**
`C#` `.NET 8` `WPF` `Claude API` `Playwright`

A Windows desktop application that lives in the system tray, watches the filesystem in real time, and automatically detects and fixes code errors using the Claude API — across 53+ programming languages.

Every AI-suggested fix is shown in a red/green diff view before it touches disk, with automatic backups on apply. Browser-side errors are captured via Playwright and routed through the same fix pipeline as local file errors. The system is built on independently testable services — `ClaudeService`, `TerminalService`, `BrowserService`, `DiffService` — rather than a single monolithic AI wrapper.

**Dyslexia Risk Evaluation System — Final Year Project**
`Python` `TensorFlow` `PyTorch` `OpenCV` `Unity` `Flask` `MySQL`

An AI system that screens children for dyslexia risk from handwriting samples and turns the result into a personalized, game-based learning path. Four deep learning architectures — CNN, ResNet, EfficientNet, and MobileNet — were trained and benchmarked on combined Kaggle and real classroom datasets to identify the strongest model.

The system builds a letter-confusion profile (b/d, p/q, n/u) from a short assessment and feeds it into an adaptive Unity learning game, alongside a teacher dashboard for risk visualization and automated PDF reporting.
